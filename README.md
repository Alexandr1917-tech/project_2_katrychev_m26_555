## Управление таблицами

- `create_table <имя> <столбец1:тип> ...` — создать таблицу
- `drop_table <имя>` — удалить таблицу
- `list_tables` — список таблиц
- `help` — справка
- `exit` — выход
- `insert into <имя_таблицы> values (<значение1>, <значение2>, ...)` — добавить запись
- `select from <имя_таблицы>` — прочитать все записи
- `select from <имя_таблицы> where <столбец> = <значение>` — прочитать записи по условию
- `update <имя_таблицы> set <столбец1> = <новое_значение> where <столбец> = <значение>` — обновить записи
- `delete from <имя_таблицы> where <столбец> = <значение>` — удалить записи
- `info <имя_таблицы>` — вывести информацию о таблице


Пример:

```

>>>Введите команду: create_table users name:str age:int
Таблица "users" успешно создана.
>>>Введите команду: list_tables
- users
>>>Введите команду: drop_table users
Таблица "users" успешно удалена.
>>>Введите команду: insert into users values ("Sergei", 28, true)
Запись успешно добавлена в таблицу "users".
>>>Введите команду: select from users
+----+--------+-----+-----------+
| ID |  name  | age | is_active |
+----+--------+-----+-----------+
| 1  | Sergei | 28  |   True    |
+----+--------+-----+-----------+
>>>Введите команду: update users set age = 29 where name = "Sergei"
Запись с ID=1 в таблице "users" успешно обновлена.
>>>Введите команду: delete from users where ID = 1
Запись с ID=1 успешно удалена из таблицы "users".
>>>Введите команду: info users
Таблица: users
Столбцы: ID:int, name:str, age:int, is_active:bool
Количество записей: 0
```

## Обработка ошибок и подтверждение действий

- **Обработка ошибок**: все операции с базой данных защищены декоратором `handle_db_errors`. При возникновении исключений (например, обращение к несуществующей таблице) программа выводит понятное сообщение и продолжает работу.
- **Подтверждение опасных действий**: при удалении таблицы (`drop_table`) или записи (`delete`) запрашивается подтверждение пользователя (`[y/n]`).
- **Замер времени**: операции `insert` и `select` логируют время выполнения.

### Пример работы

```
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: n
Операция отменена.
>>>Введите команду: drop_table users
Вы уверены, что хотите выполнить "удаление таблицы"? [y/n]: y
Таблица "users" успешно удалена.
